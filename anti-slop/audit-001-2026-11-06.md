# Antislop Audit: e-Exam STPM (audit-001-2026-11-06)

This audit evaluates the user interface against the Anti-Slop craft standards and mandatory rules (R-01 through R-40). Findings are organized by rule tier: **Hard Gate = HIGH**, **Purpose-Gate = MEDIUM**, and **Quality Locks = LOW**.

---

### Numbered Findings List

1. **HIGH — R-25: Color Contrast Failure.** The `.muted` text color (`#718096`) rendered against canvas `#f3f6fa` yields a 4.13:1 contrast ratio, failing the WCAG AA 4.5:1 threshold for normal text. It must be upgraded to `#3B4C63` (contrast 6.2:1+).
2. **HIGH — R-32: Keyboard Accessibility.** Primary buttons (`.btn`) and secondary controls lack custom `:focus-visible` indicators, resulting in poor visibility during keyboard navigation.
3. **HIGH — R-39: Semantic Interaction & Accessible Forms.** The login form wraps fields without explicit `id`/`for` label associations and omits `aria-describedby` links to error feedback.
4. **HIGH — R-27: UI State Completeness.** The dashboard provides only an optimistic static preview with no empty states or guidance for users awaiting student/teacher profile linking.
5. **MEDIUM — R-09: Eyebrow Badge Above Headline.** Both `login.blade.php` (`<div class="pill">SISTEM PEPERIKSAAN STPM</div>`) and `dashboard.blade.php` (`<div class="pill">PAPAN PEMUKA</div>`) park decorative capsule badges directly above `<h1>` headings, redundantly repeating what the headline and top navigation already state.
6. **MEDIUM — R-10 & R-13: Pervasive Glow & Glassmorphism in Legacy Files.** The preserved `legacy/login.php` template stacks purple-blue gradients (`linear-gradient(135deg, #667eea, #764ba2)`), pervasive glow (`box-shadow: 0 10px 25px var(--primary-glow)`), and multi-layer backdrop blurs.
7. **LOW — R-21: Missing Dark Mode Support.** The application currently forces a hardcoded light theme with no theme tokens or light/dark toggle to support teachers grading late at night.
8. **LOW — R-05: Generic 3-Card Template Dashboard.** The dashboard displays a generic 3-card grid (`Akaun`, `Peranan`, `Sistem`) that fills space without providing immediate academic actions or meaningful data.
9. **LOW — R-20: Unbundled Inline Styles.** Key layout styles are hardcoded into `<style>` inside `app.blade.php` rather than integrated with the configured Vite/Tailwind stylesheet pipeline in `resources/css/app.css`.
